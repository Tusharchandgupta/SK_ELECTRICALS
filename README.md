# SK Electricals — Website

This is a simple, SEO-friendly static website for SK Electricals, a local electronics & repair shop in Siswa Bazar, Maharajganj (UP).

Files:
- `index.html` — Homepage with hero, product highlights, testimonials, Google Map, CTAs.
- `about.html` — About the shop and owner.
- `products.html` — Product categories and descriptions.
- `services.html` — Service list (repairs, servicing, calibration).
- `contact.html` — Contact details and map.
- `service-areas.html` — SEO page listing all towns served (Siswa, Nautanwa, etc.) with local keywords.
- `faq.html` — SEO page with common questions (e.g., "Where to repair inverter in Siswa?").
- `inverter-repair-maharajganj.html` — High-value page for inverter services in the district.
- `weighing-scale-siswa-bazar.html` — High-value page for weighing scale sales and calibration.
- `solar-panels-maharajganj-kushinagar.html` — High-value page for solar system sales and installation.
- `gorakhpur-electronics-repair.html` — New page for Gorakhpur, Pipraich, and Campierganj services.
- `css/styles.css` — Simple responsive styles.
- `seo_keywords.txt` — SEO keywords and meta suggestions.

How to preview:
Open `index.html` in your browser (double-click the file or use a local static server).
